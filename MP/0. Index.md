# MP — Mixed Practice Drills — Index

**What an MP drill is:** a problem drawn **cold and out of pattern context** — no folder heading telling you it's DP, no neighbouring problems priming the approach. The protocol (spelled out at `daily-tracker.md:979`): **recognise the pattern in ~60 seconds, then re-solve in ≤20 minutes.** Unlike a `DSA Review: #N (D+30)` line, which is spaced repetition on a *known* problem, an MP drill tests the one skill an interview actually measures — **mapping an unlabelled statement onto a pattern you already own**. That is exactly what the `**Trigger:**` line at the top of every note is built to train.

**How this relates to the pattern folders:** `MP/` is a **log, not a note store**. Every drill note is written into its **own pattern folder** (so the pattern stays revisable as one unit, and nothing is hidden from the folder you actually revise from), and its 60-second recall row goes into that pattern's `0. Index.md`. The rows below record only **what was drilled, when, and the recognition tell** — the thing an MP drill actually trains — with a link out to the note.

## The recognition checklist (run this before writing anything)
1. **What is the answer — a count, an optimum, or a yes/no?** → `+` · `min`/`max` · `||`. Same skeleton, different combine operator; this single question separates most of the DP catalogue.
2. **What does the state depend on?** A **fixed window of the last `k`** ⇒ 1D DP, and the table collapses to `k` scalars. Two independent indices ⇒ 2D.
3. **Are the branches unconditional, weighted, or guarded?** Unconditional ⇒ 70. Weighted ⇒ 746. Guarded by a predicate ⇒ 91 / 139. Asymmetric (one skips) ⇒ 198.
4. **Is the greedy provably forced?** If you can write an exchange argument, drop the table (55/45). If you can't, you need DP.
5. **What is the empty answer?** The **identity of the combine operator** — `1` for a count, `0` for a sum of costs, `true` for an `||`. Getting this backwards breaks every derived value.
